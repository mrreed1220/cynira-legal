Cynira mobile app — SMS consent screen

This page is a faithful reproduction of the in-app opt-in screen shown to every user during account onboarding (source: src/screens/ConsentScreen.tsx), hosted here for A2P 10DLC campaign review since the native mobile app itself is not otherwise publicly browsable. Full source: Terms of Use (see "Text Messaging (SMS) Program") / Privacy Notice.

How users opt in

  1. The user creates a Cynira account in the Cynira mobile app (iOS/Android).
  2. The user enters their mobile number and verifies it with a one-time code.
  3. On the Text Check-Ins screen below, the user selects "Yes, text me check-ins" (nothing is pre-selected) and taps Continue. Choosing "Not right now" means no check-in texts are sent.
